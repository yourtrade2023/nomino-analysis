# nomino 店舗分析 共有パッケージ — セットアップ手順

会社のClaudeアカウントで、石川さんの分析セッションと同じようにDB分析できる環境を作るためのファイル一式です。**約5分で完了します。**

## 前提

- 会社側のclaude.ai アカウント（Claude Code が使えるプラン）
- 会社側のGitHubアカウント（claude.ai と連携済みであること）

## 手順

1. **GitHubに新しいリポジトリを作る**（例: `nomino-analysis`、Privateを推奨）
2. このフォルダの3ファイルをリポジトリの**ルート**に置く:
   - `CLAUDE.md` ← これが分析の「頭脳」。Claudeが毎セッション自動で読み込む
   - `query.sh`（`chmod +x query.sh` を忘れずに）
   - `sample_queries.sql`
3. [claude.ai/code](https://claude.ai/code) でそのリポジトリを選んでセッションを開始
4. 動作確認としてこう聞く:
   > 「先月と今月の売上をAOV・客数に分解して比較して」

   CLAUDE.mdの接続情報を使って自動的にDBへクエリし、分析が返ってくれば完了。

## できること / できないこと

| | |
|---|---|
| ✅ できる | 売上・在庫・顧客・販促・入札データのSQL分析（読み取り専用）、ダッシュボード閲覧 |
| ❌ できない | データの書き込み・変更、コードのデプロイ、DB資格情報へのアクセス |

## セキュリティメモ

- このパッケージに秘密情報（パスワード・APIキー）は含まれていません
- 分析ゲートウェイ `/api/query` は読み取り専用・1000行上限です
- ゲートウェイにトークン保護（`QUERY_API_TOKEN`）を有効化した場合は、管理者からトークンを受け取り、セッション内で環境変数に設定してください
